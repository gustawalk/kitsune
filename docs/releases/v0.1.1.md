# Kitsune v0.1.1

- Stage different changes across multiple rows without writing to the database.
- Review, apply, or discard all pending changes from the toolbar above the table.
- Keep staged values visible and marked when changing pages, sorting, or switching tabs.
- Apply the entire batch in one transaction. A conflict or validation failure rolls back every row and keeps your drafts available.
- Stage bulk edits to selected rows alongside individual edits.
- Warn before closing a table with pending edits and block updates while edits are pending.

This release replaces the withdrawn v0.1.0 release with the corrected editing workflow.
